# Changelog

## 1.1.0 - 2026-08-16

- Added alert rules for routing incident and recovery events to email or webhook destinations.
- Added seven alert-rule API operations, including test delivery history.
- Added typed alert-rule methods to the browser SDK.
- Added the operator-only `<pulseforge-alert-center>` web component.

## 1.0.0 - 2026-08-16

- Added public status reads and authenticated incident management.
- Added the typed browser SDK.
- Added the `<pulseforge-status>` web component.
